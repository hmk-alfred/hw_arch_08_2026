\section{Worklog}
\label{sec:worklog}

\small
This appendix is a running record of engineering/document sessions, appended to (never rewritten) each time work resumes. See \code{worklog/WORKLOG.md} in the project repository for the plain-text/git-friendly version of the same log; this section is the version that renders into the PDF. To add an entry in a new session, append a new \code{\textbackslash worklogentry\{...\}} block to \code{worklog/worklog\_entries.tex} --- do not edit or remove prior entries.
