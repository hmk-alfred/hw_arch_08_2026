\section{Prototype Component Recommendations}
\label{sec:bom}

\begin{risknote}[title={Read this before the table}]
A consumer/industrial dev board is not automatically production-suitable. The table below deliberately separates \emph{what to buy today to build a working prototype} from \emph{the component class a production program must qualify to}. Treat the "Prototype" column as disposable engineering-sample hardware; treat the "Production-automotive class" column as the real design target requiring AEC-Q100/Q200 qualification, automotive temperature grade (typically $-40$ to $+125^\circ$C junction), and, for anything safety-relevant, a documented safety manual/FMEDA from the supplier.
\end{risknote}
