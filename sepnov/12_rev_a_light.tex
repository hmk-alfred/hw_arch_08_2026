\section{Rev A-Light --- LAN8661 Development Board}
\label{sec:rev-a-light}

Tightly related to Rev~A-Control (Section~\ref{sec:rev-a-control}), sharing power, T1S connector/termination, monitoring, test-point strategy, board size, mounting, status indicators, and manufacturing approach; local-interface circuitry differs to match LAN8661's lighting-specific job.

\subsection{What Rev A-Light exposes}

\begin{itemize}[itemsep=0.1em]
\item LAN8661.
\item 10BASE-T1S pair, coupling/termination matching Rev~A-Control's approach.
\item Lighting-related interfaces (whichever of I$^2$C/SPI the confirmed reference design uses to reach an LED-driver IC).
\item Test points for the lighting-driver control bus, independent of the LED load itself.
\item Power measurements (supply current with load on/off, to characterize the LED driver's contribution separately from LAN8661's own consumption).
\item Configuration access consistent with Rev~A-Control's approach.
\item A connection to the selected LED-driver demonstration hardware (Section~\ref{sec:lan8661-validation}) -- a simple LED driver/load, not optimized for production packaging.
\end{itemize}

This gate must pass \emph{before} Rev~B architecture freezes (Section~\ref{sec:timeline}, October~10 hard gate) -- Rev~B is not started on an unverified assumption about either part's real-world behavior.
