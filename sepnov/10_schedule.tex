The table below is the working schedule; owners are functional disciplines (PM = program management, HW-Net = MCU/T1S/PLCA hardware, HW-Power = power architecture, HW-Bus = CAN/CAN-FD/LIN hardware, Layout = PCB layout, Firmware = embedded firmware, Test = bring-up/validation, Procurement = purchasing) rather than named individuals, since role assignment is a staffing decision outside this plan's scope.
